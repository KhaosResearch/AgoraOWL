Bridge vocabulary for observable properties used with AgoraOWL. NOT IMPORTED by the core ontology. This file exists to improve discoverability, lexical normalization, and crosswalks to external vocabularies. Policy: 1. Use external URIs directly when they are sufficient. 2. Mint local concepts only when they add value, such as acronyms, aliases, project-stable identifiers, or concepts without a reliable external match. 3. Link local concepts to external vocabularies with skos:exactMatch or skos:closeMatch whenever possible. This vocabulary intentionally focuses on ObservableProperty-like concepts. Features of interest such as Building, Water, or Vegetation are out of scope.

Vocabulario puente de propiedades observables usado con AgoraOWL. NO es importado por la ontología principal. Este fichero existe para mejorar la descubribilidad, la normalización léxica y los crosswalks con vocabularios externos. Política: 1. Usar URIs externas directamente cuando sean suficientes. 2. Acuñar conceptos locales solo cuando aporten valor, como acrónimos, alias, identificadores estables o conceptos sin correspondencia externa fiable. 3. Enlazar conceptos locales con vocabularios externos via skos:exactMatch o skos:closeMatch siempre que sea posible. Este vocabulario se centra intencionalmente en conceptos de tipo ObservableProperty. Las características de interés como Edificio, Agua o Vegetación están fuera de ámbito.
